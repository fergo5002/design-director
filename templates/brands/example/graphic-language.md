# Example Studio graphic language

## Do

- Warm paper ground, ink text, the rust accent for one thing per screen.
- Square corners (4px at most), hairline rules in the rule colour.
- Fraunces for display at large sizes only; Public Sans for everything else.

## Do not

- No dark mode: the brand is light only.
- No gradients, glass or drop shadows. Print has none of them.

## Lessons

### Prices sit on the baseline grid {#L-2026-11-05-price-grid}

A price table set off the grid read as a template in review. Prices now align to the text
baseline, in the text face, never the display face.
